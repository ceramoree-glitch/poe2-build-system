# PoE2 Build System
## Klasör Yapısı
- SKILL/ - Skill gem verileri
- ASCENDANCY/ - Ascendancy verileri
- UNIQUE/ - Unique item verileri
- KEYWORDS/ - Anahtar kelimeler
- CONSTITUTION/ - Kurallar ve anayasa
- FUTURE_MECHANICS/ - Gelecek mekanikler
- DATA/ - İşlenmiş veriler
- SRC/ - Kaynak kodlar
- OUTPUTS/ - Raporlar ve çıktılar
- SCRIPTS/ - Çalıştırma scriptleri
- CONFIG/ - Yapılandırma
